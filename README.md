# Gossip Girl School Edition

A chic, Pinterest/editorial-style school website inspired by the supplied Gossip Girl reference.

## Included
- Pink/cream Gossip Girl-inspired landing page
- Hero layout echoing the supplied birthday-site reference
- Blair/Upper East Side visual language
- Decorative photo frames, gold details, polaroids, scrapbook-style gallery
- All six supplied images included in `assets/`
- Spotted section
- School calendar section
- Send a Gossip form
- Local editorial inbox with Pending submissions
- Mobile responsive layout

## Important: receiving submissions for real
The included form is a safe prototype. It stores submissions only in the browser's localStorage, so it is NOT a real shared inbox.

For a real school deployment, connect the form to a private Google Form/Google Sheet or a small backend. The public page should send submissions to that service, while only the editor has access to the inbox. Do not put an admin password in public HTML/JavaScript.

## GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).
